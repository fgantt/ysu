# Background artwork and Settings gallery

Created with the built-in image-generation tool. Originals remain in the Codex generated-images directory; all ten final project assets are saved in public/boards and public/wallpapers. Existing images remain available.

Board pictures are square with restrained central detail for grid/piece legibility. Wallpapers are landscape scenes with varied photographic, painterly and paper-cut styles.

Settings retains its tabs, previous tab/collapse/scroll state and immediate selection callbacks. Backgrounds now has named keyboard-accessible cards, larger current previews, search, a New artwork filter, and selected checkmarks. Board previews include a sample grid and pieces. The panel is roomier with spaced sections; narrow screens use a horizontally scrollable tab bar.

Browser verification confirmed that all five board PNGs decode successfully; native runtime refresh remains for the user to confirm.
